# Requisitos iniciais — legado

1. O sistema deve permitir abrir chamados.
2. Deve distribuir chamados entre técnicos.
3. Deve controlar prioridades.
4. Deve cumprir SLA.
5. Deve permitir escalonamento.
6. Deve notificar usuários.
7. Deve integrar alertas de monitoramento.
8. Deve integrar fornecedores externos.
9. O solicitante precisa acompanhar o status do seu chamado, para saber se ele está aberto, atribuído, resolvido ou escalado.
10. Deve responder rapidamente.
11. Deve ser fácil de manter.

Os requisitos não possuem critérios de aceitação suficientes.
